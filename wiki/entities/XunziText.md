# 《荀子》 / Xunzi

## Overview
《荀子》的王霸、王制、议兵论证在播客中分别用于审视君主、行政与战争。

## Current Profile
《荀子》在登记笔记中是经《资治通鉴》及播客援引的思想文本，而非本项目直接校勘的原典。王霸、王制与议兵的不同论证，分别处理政权信用、行政民心与战争约束。

## Key Characteristics
- 《王霸》把礼义、守信与欺诈分列为不同政治后果。
- 《王制》用政事与民心对照财富积累，并被用于评议具体治国者。
- 《议兵》把民众认同、军纪及指挥伦理放在地形、速度和欺诈之上。
- 司马光引述与播客讲解形成多层文本中介，不能把节目口号直接当原典逐字引文。

## Evidence
- [[SimaGuang|司马光]]在[[ZizhiTongjian|《资治通鉴》]]借《王霸》评[[QiMinWang|齐湣王]]：不义而富兵强仍会内外孤立，礼义可王，信用可霸。[[zizhi-tongjian-zhouji-71-xunzide-xingbenelun-lnyfxoxauexhwbrwkdevs8m4mr2j]] 此处是史家采用文本教君主，不是齐亡的单一可测原因。
- 《王制》的礼义、政事、民心、聚财四重排序在谈[[WeySijun|卫嗣君]]的[[SurveillanceBasedRulerControl|暗察制衡君术]]时被调用；后者是节目中的对照而非《荀子》认可其治理手段，[[PeopleBasedPoliticalSecurity|民心所系的安全]]不是侦察所能取代。[[zizhi-tongjian-zhouji-74-huanyuan-wanbi-guizhao-zhenxiang-lg1irvbbc1wp8oph2kmpatfoxebk]] 对[[ZiChan|子产]]善举与[[GuanZhong|管仲]]行政能力的比较，进一步区分[[GoodIntentionsPoliticalLimits|私人仁惠]]、能政与修礼，齐桓公在管仲身后失序说明[[PersonDependentGovernanceFragility|人亡政息]]的风险。[[zizhi-tongjian-zhouji-75-1-qiongshe-jichi-de-zushiye-guanzhong-lmeeh8t6dobgzrkoouato9vhjjuj]]
- 在[[ZhaoDan|赵丹]]面前，[[LinwuJun|临武君]]重天时、地形、速度和诡道；《议兵》的讲解转向[[XunzianMilitaryLegitimacy|上下同欲的仁义之师]]，并指出[[ProfitDrivenArmyLimits|仅靠赏罚激励的军队]]不能取代政治凝聚，并以[[XunzianCommandRestraint|五权三制]]限制将领贪功与伤民。[[zizhi-tongjian-qinji-99-3-xunzi-bingfa-li-cangzhe-renxing-de-mimi-lgfcp4hkruyhhrjguqhjbhllvwp43]] 兵种高下是这段论辩中的评价，非完整军事制度比较。
- 《王霸》经《通鉴》转引并可能改写；节目顺带提及“成像片”疑为《成相》，但没有展开篇内论证。[[zizhi-tongjian-zhouji-71-xunzide-xingbenelun-lnyfxoxauexhwbrwkdevs8m4mr2j]] 所谓[[XingETheory|性恶论]]与《王霸》相关于[[Xunzi|荀子]]的政治教育框架，却不能由一句音转不稳的篇名证明具体文本。

## Qualifications
所有四条 Source Note 均为播客讲读，不是原典直校；《王霸》《王制》章名与被引用字句的关系应分清。子产渡河故事还借孟子评论，不能全归荀子。五权三制的节目释义可能非逐字原文。

## What Changed
- 将文本的政治等级、应用案例、兵论分为三种证据功能。

## Relationships

- [[XunzianWangbaThreePaths]] - 《王霸》讨论不同治国方式的后果。
