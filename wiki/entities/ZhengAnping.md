# 郑安平 / Zheng Anping

## Overview
郑安平先帮助受魏齐迫害的范雎逃离魏国并接触王稽，后因旧恩获范雎举荐为秦将；邯郸援赵战中率秦军投降，举荐人范雎因此面临秦国法律和政治风险。

## Current Profile
此页的线索是个人救助如何转为公职用人责任，而非把一次降赵概括为范雎所有用人失败；两期对投降的记述指同一事件。

## Key Characteristics
- 救助被迫害的范雎，使其隐匿并获得通往秦国的机会。
- 范雎以旧恩举荐郑安平，私人酬谢转为国家军职风险。
- 邯郸解围之际率约两万秦军降赵，战场态势与个人行为相连。
- 秦王免范雎连坐并禁论此事，显示法制声称与君主特赦之间的张力。

## Evidence
- **从施援到举荐：** 郑安平在范雎受魏齐酷刑、诈死后助其离开险境、隐匿为张禄，并与王稽引荐路线相接；播客主要借其交情解释范雎后来的政治上升。[[zizhi-tongjian-zhouji-88-ni-zenme-kandai-fenghuangnan-1-lpuxkdq-rvnifuoneq212g53w5z5]] 范雎在秦报恩推荐他，节目质疑用国家职位报私人恩情是否匹配受任能力，但这属播客的用人伦理评价。[[zizhi-tongjian-zhouji-97-2-jiemi-xinlingjun-ping-shenme-shi-si-gongzi-zhi-shou-lodqntthbil9o8ezppt66lywzd-f]]
- **战争与连坐：** 信陵君窃符调魏军、联楚赵解邯郸围后，郑安平率约两万秦兵降赵，王龁后撤；96 与 97-2 叙同一次降军，不能重复计数。[[zizhi-tongjian-zhouji-96-maosui-zijian-6-lteqe-0ykjtv01cmxv1fhx6z0vdi]] [[zizhi-tongjian-zhouji-97-2-jiemi-xinlingjun-ping-shenme-shi-si-gongzi-zhi-shou-lodqntthbil9o8ezppt66lywzd-f]] 按节目所述秦律举荐人应受牵连，但秦昭襄王保范雎并禁朝臣议此事，显示权力可为个别宠臣设例外。[[zizhi-tongjian-zhouji-97-2-jiemi-xinlingjun-ping-shenme-shi-si-gongzi-zhi-shou-lodqntthbil9o8ezppt66lywzd-f]]
- **晚期余波：** 蔡泽劝范雎功成身退时，郑安平与王稽作为范雎此前举荐旧人的问题被提起，成为其政治负担。[[zizhi-tongjian-qinji-99-2-mingming-yilian-baixiang-de-caize-ping-shenme-baixiang-lhfyb6hzcqkpbzdrwsxajb7hhmhe]]

## Qualifications
- 两万是节目叙述的兵力，不独立核验；救助、归降均来自播客转述古史，不宣称其内心意图已证。[[zizhi-tongjian-zhouji-88-ni-zenme-kandai-fenghuangnan-1-lpuxkdq-rvnifuoneq212g53w5z5]] [[zizhi-tongjian-zhouji-96-maosui-zijian-6-lteqe-0ykjtv01cmxv1fhx6z0vdi]]
- Qinji 99-2 只提郑安平与王稽给范雎带来政治负担，不提供郑安平死亡日期或武阳封邑变动的证据。[[zizhi-tongjian-qinji-99-2-mingming-yilian-baixiang-de-caize-ping-shenme-baixiang-lhfyb6hzcqkpbzdrwsxajb7hhmhe]]

- 郑安平救范雎脱离[[PrivatePunishmentWithoutProcedure]]，入[[QinState]]仍依王稽渠道；[[WarringStatesCareeristMobility]]仅是相邻解释框架。[[zizhi-tongjian-zhouji-88-ni-zenme-kandai-fenghuangnan-1-lpuxkdq-rvnifuoneq212g53w5z5]] 秦将[[WangHe]]后撤与[[TalentReferralQuality]]的举荐责任并非同一行动；[[CaiZe]]所提[[PowerExitTrap]]属于范雎退位劝说。[[zizhi-tongjian-zhouji-96-maosui-zijian-6-lteqe-0ykjtv01cmxv1fhx6z0vdi]] [[zizhi-tongjian-zhouji-97-2-jiemi-xinlingjun-ping-shenme-shi-si-gongzi-zhi-shou-lodqntthbil9o8ezppt66lywzd-f]] [[zizhi-tongjian-qinji-99-2-mingming-yilian-baixiang-de-caize-ping-shenme-baixiang-lhfyb6hzcqkpbzdrwsxajb7hhmhe]]

- [[StealingTigerTalliesToRescueZhao]] - 魏军解邯郸围的行动背景，不是郑安平的谋划。
