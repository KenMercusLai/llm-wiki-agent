# 郑国 / Zheng State

## Overview
郑国横处晋、楚与战国韩势力之间，早期既能趁韩景侯死攻阳翟，也遭楚围新郑；子阳被杀后的派系反攻使郑繻公死、郑康公立。韩多次夺其城邑，最终于 375 BCE 灭郑并迁都新郑。子产一段则属于更早春秋背景，不与战国政变混作同一世代。

## Current Profile
小国夹缝外交、内廷暴力与逐步失土相互叠加，但资料的短年表和节目对《清华简·系年》的补叙并不足以断言每次外敌围城都直接由同一派系内争造成。

## Key Characteristics
- 战略位置使郑难同时取悦晋楚，局部攻韩反而暴露边境。
- 子阳被杀、郑繻公被弑与郑康公被立显示内廷派系斗争。
- 负黍归属反复、韩夺阳城显示领土控制不断受挑战。
- 韩在长期压力后灭郑、迁新郑，王国终结但都城继续被利用。

## Evidence
- **早期治理与地缘前提：** 春秋子产个人渡人过河的仁心被节目与制度性治水区分；攻蔡成功后他仍担忧晋楚夹击。这是距战国灭郑数代的回顾，而非子产预知 375 BCE。[[zizhi-tongjian-zhouji-75-1-qiongshe-jichi-de-zushiye-guanzhong-lmeeh8t6dobgzrkoouato9vhjjuj]] 郑庄公时期曾强盛，但位置介于晋楚使其很难固定选边；节目据《系年》补充《通鉴》没有说明的楚围郑、子阳死事动机，须保留补史属性。[[zizhi-tongjian-zhouji-07-liangqi-cisha-1-lvkp-ju7pf5z5cz3thojv3s2fkyx]]
- **战争与政变相交：** 400 BCE 韩国韩景侯死后郑围阳翟，楚又围新郑；同时郑相子阳遇害。[[zizhi-tongjian-zhouji-07-liangqi-cisha-1-lvkp-ju7pf5z5cz3thojv3s2fkyx]] 子阳余党于 396 BCE 杀郑繻公而立郑康公，是内乱的后续，而非另一起同日政变；394 BCE 负黍自郑返韩，旋又受楚控制，显示据点归属流动。[[zizhi-tongjian-zhouji-07-liangqi-cisha-2-lhngst3xsnyjrmzh1cvheocvvsqm]]
- **领土侵夺到终局：** 韩在 385 BCE 攻郑取阳城只见短战报，不可扩成完整征服过程。[[zizhi-tongjian-zhouji-08-yidai-mingjiang-wuqi-cansi-3-ltca-ikuzo9ej7a0lfrgwv2-wulb]] 375 BCE 韩灭郑并迁都新郑，来源以数代韩国对郑的持续压迫解释结局；都城移用不等于郑国政权存续。[[zizhi-tongjian-zhouji-10-yi-jiazu-danwei-you-mayi-chi-daxiang-de-jingshen-1-lq3t7lwpmq1oyb8zmmmn2tywnu8d]]

## Qualifications
- 春秋子产与战国末段年代分离；“郑国被夹击”的结构性解释不代替每次军情的直接证据。[[zizhi-tongjian-zhouji-75-1-qiongshe-jichi-de-zushiye-guanzhong-lmeeh8t6dobgzrkoouato9vhjjuj]] [[zizhi-tongjian-zhouji-07-liangqi-cisha-1-lvkp-ju7pf5z5cz3thojv3s2fkyx]]
- 385 BCE 韩夺阳城仅一条年表；负黍多次变主不可简化成韩持续单向扩张。[[zizhi-tongjian-zhouji-08-yidai-mingjiang-wuqi-cansi-3-ltca-ikuzo9ej7a0lfrgwv2-wulb]] [[zizhi-tongjian-zhouji-07-liangqi-cisha-2-lhngst3xsnyjrmzh1cvheocvvsqm]]

- 子产渡人的[[Mengzi]]转述显示[[GoodIntentionsPoliticalLimits]]，与战国亡郑相隔甚远。[[zizhi-tongjian-zhouji-75-1-qiongshe-jichi-de-zushiye-guanzhong-lmeeh8t6dobgzrkoouato9vhjjuj]] 韩国的[[GenerationalFamilyStrategy]]被节目追溯到[[HanKangzi]]、[[HanWuzi]]、[[HanAihou]]数代，不能证明每人亲自参与每场伐郑。[[zizhi-tongjian-zhouji-10-yi-jiazu-danwei-you-mayi-chi-daxiang-de-jingshen-1-lq3t7lwpmq1oyb8zmmmn2tywnu8d]]

## What Changed
- 将春秋治理的远景、早战国宫廷变局与韩国终结分层。
- 把韩逐步侵夺与楚、晋压力并列，而非编造一条单一的连续灭国战役。
